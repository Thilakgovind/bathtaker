## The fault and the fix
`BoardLink` was a subclass of `threading.Thread` and had a method named `_handle`. Python 3.13 keeps its own
`_handle` on every thread, so the method overwrote it. Antigravity renamed the method to `_process_line`.

Follow-up (Claude): the same class also had `self._stop`, which overwrites a method that Python 3.11 and 3.12
use when a thread ends. `BoardLink` no longer subclasses `Thread`; it holds one. A new check,
`test_link_starts_and_stops_cleanly_with_no_board`, starts and stops the link. `httpx` was added to
`requirements.txt` because the test client needs it.
