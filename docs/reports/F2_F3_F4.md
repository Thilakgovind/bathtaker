# F2, F3, F4: the screen, live

Antigravity's F2 built but did not work, and it could not open the page to see that. Claude rebuilt
`frontend/src` from the design export and checked it in a real browser (headless Chromium, 1440 x 900)
against the pretend board. Everything below was looked at on screen, not only compiled.

## What was wrong in the first F2
- The headline and the "Mark as cleaned" button were pushed off the screen by a wrong line height.
- The pretend board's data was labelled "LIVE FROM THE BOARD ON COM5".
- The Door tile read a field that does not exist, so it always said "Vacant".
- The headline was read once at start and never updated; unplugging the board did not show.
- Events were kept in mixed order.

## What was checked in the browser (pretend board, made-up data, no model)
| Step | Seen on screen |

| Start | "FREE", "0 USES", a dash and "LEARNING THIS ROOM'S NORMAL AIR" until the board learned it; strip reads PRETEND BOARD, SAMPLE DATA |

| "Shift report", "What needs me?" | Cards with figures that match the event strip |
| "Turn the fan on when humidity is above 150" | "Humidity must be between 0 and 100%. You gave 150." and no Approve button |

| Window 1100 x 700 and 390 x 800 | No sideways scroll (the canvas scales to fit) |

Also run: `python -m pytest -q` (27 passed on Python 3.11 and 3.13), `npm run build`.
